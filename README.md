# PII GUARD

Real-time browser extension for AI prompt protection and sensitive data leak prevention.

---

## Features

- Real-time PII detection
- AI prompt protection
- Severity classification
- Floating risk dashboard
- Clipboard monitoring
- Interactive highlighting
- Secure masking
- ChatGPT-compatible monitoring

---

## Supported Detection

- Email Addresses
- Phone Numbers
- Aadhaar Numbers
- PAN Cards
- Credit Cards
- OpenAI API Keys
- AWS Keys
- JWT Tokens

---

## Tech Stack

- JavaScript
- Chrome Extension Manifest V3
- DOM Monitoring
- Content Scripts
- Browser Security Engineering

---

## Installation

### 1. Clone Repository

```bash
git clone https://github.com/ajit028/pii-guard-extension.git
```

### 2. Open Chrome Extensions

Go to:

```txt
chrome://extensions
```

### 3. Enable Developer Mode

Turn ON:
- Developer Mode

### 4. Load Extension

Click:
- Load unpacked

Select the project folder.
